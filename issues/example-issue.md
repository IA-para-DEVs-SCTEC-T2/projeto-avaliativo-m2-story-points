# Exemplo de Issue para Teste

Use o conteúdo abaixo como entrada para o agente ao executar `python main.py`.
Basta substituir o valor de `test_issue` em `main.py` pelo texto desejado.

---

## Issue 1 — Complexidade Alta (esperado: 8 ou 13 pontos)

```
Título: Implementar sistema de login com OAuth2 (Google)
Descrição:
- Criar tela de login com botão 'Entrar com Google'
- Configurar credenciais no Google Cloud Console
- Implementar fluxo OAuth2 no backend (Python/FastAPI)
- Salvar token de acesso e refresh token no banco de dados (PostgreSQL)
- Criar middleware de autenticação para proteger rotas privadas
- Adicionar testes unitários e de integração
```

---

## Issue 2 — Complexidade Baixa (esperado: 1 ou 2 pontos)

```
Título: Corrigir texto do botão de cancelar
Descrição:
- O botão de cancelar na tela de checkout exibe 'Cancelar Pedido'
- O texto correto deveria ser 'Voltar'
- Alterar apenas o label no componente React
```

---

## Issue 3 — Issue Inválida (esperado: rejeição pelo agente)

```
Título: Melhorar o sistema
Descrição: Precisamos melhorar algumas coisas no sistema.
```
